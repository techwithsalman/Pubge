* **Core Structure**: Semantic HTML5, SVG Vectors & Inline Gradients
* **Styling**: Component-scoped CSS, Custom Properties, Responsive Media Queries
* **Interactivity**: Pure Vanilla JavaScript Controller (No bloated runtime dependencies)

* **Hosting Support**: Fully static architecture — runs on any HTTP server, Netlify, Vercel, or GitHub Pages.

## 💻 Local Development

To run the portfolio locally:

```bash
# Clone the repository
git clone https://github.com/techwithsalman/Pubge.git
cd Pubge

# Run with any static HTTP server (e.g. Python)
python -m http.server 3000

# Open in your browser
# http://localhost:3000/
```

Or using Node.js:
```bash
npx serve .
```
